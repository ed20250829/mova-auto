# IDEAS — Мова

Рабочий документ. Решения владельца — сюда комментарием.

## Бренд (на согласование)

Рабочий бренд сейчас: **Мова**. Слоган на сайте: **«Язык твоего авто»** (понятно за 3 секунды).

Альтернативы в том же поле (локальность / язык / «машина понимает»):

1. **Гутарка** — белорусское «разговор, речь». Теплее и «своё», но длиннее и хуже латиницей (`gutarka`). Риск: звучит мягче, чем экспертный сервис.
2. **Слова** — коротко, по-белорусски/по-русски нейтрально. Доменный риск. Слабее уникальности.
3. **Razmova** — «размова» латиницей. Хорошо для .tech / IG, сразу читается иностранцами в Беларуси. Чуть дальше от кириллического тепла.
4. **Movai** — Мова + AI-намёк без слова «AI» в бренде. Опасно: уводит в «софт-стартап», не в автосервис.
5. **Панятны** — «понятный». Прямой оффер в имени. Сложнее как бренд-знак, дольше писать.

Рекомендация: оставить **Мова**, если нет сильного возражения. Локально, коротко, без «русского» в имени, хорошо садится на mova-auto.tech.

Другие слоганы (запас):
- «Мова — твоя машина говорит по-русски»
- «Меню по-русски. Цена на сайте.»

## Бизнес-возможности

1. **Пакет «импортёр 10»** — предоплата пакета слотов на месяц со скидкой 12–15%. Предсказуемая загрузка вечеров.
2. **Апселл на месте:** карта офлайн (если клиент просит), обучение «как откатить OTA», продажа кабель/адаптер в партнёрке.
3. **Контент-машина:** короткие Reels «китайский экран → русский» по одной модели в неделю. SEO-страницы `/auto/...` уже дают посадочные под каждый ролик.
4. **Диагност-партнёрка 10%** уже заложена в типе партнёра `diagnostic`. Закрыть 5 диагностов в Минске = дешевле VK Ads.
5. **Салон white-label:** отчёт без бренда Мова в клиентском акте — отдельный PDF-шаблон в админке.
6. **Сегмент «автокредиты / лизинг-менеджеры»** — им нужны машины «готовые к выдаче». Тот же опт, другой CTA.

## Конверсия и продукт

1. Калькулятор в hero уже снимает главную боль «от 650, приезжайте». Дальше: показывать **гарантию 6 мес** рядом с итогом (микрокопия).
2. После выбора hard-модели — мягкий nudge на OTA-страховку (сейчас авто-чек).
3. Thank-you рефералка 100 BYN — добавить уникальный код `REF{orderId}` в админке, чтобы не верить на слово.
4. Промокод MOVA10: ограничить 1 раз на телефон (поле в orders уже есть).

## Технические идеи

1. **Vercel + better-sqlite3** на serverless плохо дружит с локальным файлом. Варианты: Turso/libSQL, Neon Postgres, или Vercel Postgres. Команда `npm run db:migrate:pg` уже готовит DDL.
2. Вынести seed в CI-check: `models.length >= 40`.
3. Добавить Playwright на калькулятор + booking validation + admin 401.
4. Хранить Telegram `chat_id` клиента после первого контакта с ботом — тогда «Отправить статус» станет реальным, не заглушкой.
5. Geo Минск vs область: сейчас задел в analytics copy; следующий шаг — поле `geo` в events с ручным выбором в форме или IP-lookup.

## Удержание / подписка OTA

1. **Напоминание за 14 дней** до `next_payment_at` (кнопка в админке есть — автоматизировать cron).
2. **Семейный план:** вторая машина +40% к годовой цене.
3. **Churn offer:** если отменяет — разовое «вернём язык после ближайшего OTA за полцены».
4. Мини-отчёт раз в квартал: «ваше авто на прошивке X, известных сбросов Y» — повод остаться.
5. Стек push: Telegram-бот как канал №1 удержания, SMS только fallback.

## Решения, принятые без спроса

- Слоган на сайте: «Язык твоего авто».
- OTA-страховка: **150 BYN/год**, выезд: **100 BYN** (калькулятор-опции; базовые цены моделей не менялись произвольно — реалистичная сетка в seed).
- Auth админки: shared secret `ADMIN_TOKEN` в cookie (passwordless по брифу).
- Деплой-адаптер: `@astrojs/vercel`.
